## Google Apps Script
`google-apps-script/Code.gs` 已包含目前最新版：
- 報名資料寫入 Google Sheet
- 「設定」分頁自動建立
- B2 開放／關閉報名
- B6:B9 管理銀行與匯款資訊
- 額滿時後端同步停止收件

若網站端更新不涉及 Apps Script，不需要重新部署 Code.gs；若之後有修改 Code.gs，請在 Apps Script 使用「新版本」重新部署，原 /exec 網址可維持不變。
